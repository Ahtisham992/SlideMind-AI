# 🚀 Cloud Run Deployment Guide

Follow these steps to deploy SlideMind AI to Google Cloud Run.

## 1. Prerequisites
- [Install gcloud CLI](https://cloud.google.com/sdk/docs/install)
- Log in: `gcloud auth login`
- Init project: `gcloud init`

## 2. Deploy Backend (API)
```powershell
cd backend
gcloud run deploy slidemind-api --source . --allow-unauthenticated
```
**Copy the URL provided at the end (e.g., https://slidemind-api-xyz.run.app)**

## 3. Deploy Frontend (UI)
```powershell
cd ../frontend
gcloud run deploy slidemind-ui --source . --allow-unauthenticated --set-env-vars NEXT_PUBLIC_API_URL=[YOUR_BACKEND_URL]
```

## 4. Environment Variables
If you need to update your Gemini API key in the cloud:
```powershell
gcloud run services update slidemind-api --set-env-vars GEMINI_API_KEY=your_key_here
```
